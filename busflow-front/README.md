# busflow-front

Dashboard web do BusFlow (Next.js 15 + Tailwind CSS 4). Veja o [README principal](../README.md).

```bash
npm install
npm run dev   # http://localhost:3000
```

> Os dados exibidos ainda são mockados em `src/app/page.tsx`; a integração com a API (`GET /bus`, `GET /bus-stop`) está no roadmap.
